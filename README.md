# Masala Deutsch — entry page

Front door for [masaladeutsch.blogspot.com](https://masaladeutsch.blogspot.com):
what the blog is, its latest articles, and every piece grouped by topic.

The page holds no article list of its own — it reads the blog's feeds when
opened, so it never goes out of date. Built by `tools/build_index_page.py`
in the blog's archive repo.
